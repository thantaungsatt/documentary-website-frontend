# Content Publishing System (Knowledge / Article Platform)

A full-stack web application for publishing long-form articles, documentation, and structured knowledge bases (similar to a specialized Wiki platform). Features role-based access for readers, contributors, and administrators.

## Key Features

* **Rich Content Management:** Supports structured articles, categories, tags, and rich-text editing.
* **Role-Based Access Control:** Public access for readers; protected routes for content authors and administrators.
* **Search & Categorization:** Fast searching and filtering across published content topics.

## Tech Stack

* **Backend:** Java, Spring Boot, Spring Security, RESTful APIs
* **Frontend:** React, TypeScript, Tailwind CSS
* **Database:** MySQL
